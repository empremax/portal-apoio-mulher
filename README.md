# Portal de Apoio e Proteção à Mulher

Um portal web completo com recursos, informações e canais de denúncia para mulheres em situação de vulnerabilidade.

## Desenvolvido por

**Matheus Ferreira**  
Aluno de Ciências da Computação - UFBRA

## Recursos

O portal oferece 30 recursos organizados em 6 categorias:

- **Denúncia e Segurança**: Canais para denunciar violência e crimes
- **Apoio Jurídico e Psicológico**: Atendimento profissional gratuito
- **Capacitação e Educação**: Cursos e programas de inclusão
- **Saúde e Bem-estar**: Informações sobre saúde da mulher
- **Informação e Direitos**: Legislação e órgãos de proteção
- **Segurança Digital**: Proteção online e remoção de conteúdo

## Linhas de Emergência

- **180**: Central de Atendimento à Mulher (24h)
- **188**: Centro de Valorização da Vida - CVV (24h)
- **100**: Disque Direitos Humanos (24h)
- **190**: Polícia Militar

## Tecnologias

- React + TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- Express.js

## Como executar localmente

```bash
pnpm install
pnpm dev
```

O site estará disponível em `http://localhost:3000`

## Build para produção

```bash
pnpm build
```
